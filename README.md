# My Academic Hub

Create a modern personal academic tracking website for a college student.

Purpose:
The website is for a single student to track attendance, marks, study materials and academic progress.

Authentication:

Simple login system.

Personal dashboard after login.

All data belongs only to the logged-in student.

Dashboard:

Display overall attendance percentage.

Display subject-wise attendance percentage.

Display Mid-1 marks.

Display Mid-2 marks.

Display Semester exam marks.

Display GPA/CGPA calculator.

Display upcoming exams and tasks.

Show attendance shortage alerts below 75%.

Attendance Module:

Create custom subjects.

Add weekly timetable.

Mark attendance for every class hour.

Mark Present, Absent or Leave.

Automatically calculate:

Subject-wise attendance percentage.

Daily attendance percentage.

Weekly attendance percentage.

Monthly attendance percentage.

Overall attendance percentage.

Show attendance statistics with charts and graphs.

Predict attendance percentage if future classes are attended or missed.

Marks Module:

Add subjects manually.

Enter Mid-1 marks.

Enter Mid-2 marks.

Enter Assignment marks.

Enter Lab marks.

Enter Semester exam marks.

Show subject-wise performance.

Calculate averages automatically.

Show progress graphs.

Study Materials Module:

Upload PDFs.

Upload Question Papers.

Upload Notes.

Upload Images.

Upload Documents.

Create folders by subject.

Search files quickly.

Download and preview files.

Question Paper Archive:

Store previous year question papers.

Organize by subject and semester.

Add tags and descriptions.

Quick search functionality.

Important Documents Module:

Store hall tickets.

Store certificates.

Store fee receipts.

Store academic documents.

Secure file storage.

Task Manager:

Add assignments.

Add project tasks.

Add exam reminders.

Add deadlines.

Mark tasks as completed.

UI Requirements:

Beautiful modern student dashboard.

Mobile-friendly responsive design.

Dark mode and Light mode.

Professional charts and analytics.

Fast and simple navigation.

Technology:

React frontend.

Node.js backend.

PostgreSQL/Supabase database.

Secure cloud file storage.

Authentication system.

Generate:

Complete frontend code.

Complete backend code.

Database schema.

Attendance calculation logic.

Marks calculation logic.

File upload system.

Mobile responsive design.

Deployment instructions.

The website should function like a complete personal student academic management system where I can manage attendance, marks, PDFs, question papers, notes and semester records in one place.
